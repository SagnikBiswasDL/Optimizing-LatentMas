\begin{frame}{The gap}

\begin{itemize}
  \item Paper numbers use the \textbf{Hugging Face} LatentMAS path.
  \item Authors' ``vLLM support'' still runs latent agents on a second HF copy, then hands off via \texttt{prompt\_embeds} and a re-prefill.
  \item That handoff drops the in-engine KV and blocks the Judger on a CPU/GPU transfer.
\end{itemize}

\vspace{0.5em}
\textbf{Contribution:} a vLLM 0.11.1 fork where Planner / Critic / Refiner latent steps and Judger decode share one request and one KV.

\end{frame}

\begin{frame}{What the fork does}

\begin{itemize}
  \item Flag a request with a phase schedule: latent $\rightarrow$ role tokens $\rightarrow$ \ldots $\rightarrow$ decode.
  \item Latent step: next input is \texttt{realign(last\_hidden)} written into \texttt{inputs\_embeds}, not a sampled token embedding.
  \item Role prompts append as ordinary tokens on the \emph{same} request.
  \item Latent embeddings are stored so preemption / recompute replays them.
  \item Start with \texttt{enforce\_eager}, async scheduling off; stock or tail scheduler via \texttt{scheduler\_cls}.
\end{itemize}

\end{frame}

\begin{frame}{Correctness vs Hugging Face}

\begin{itemize}
  \item Prompt token ids match; forced preemption replays stored latent embeds.
  \item First latent of each agent: cosine $\approx 0.999$ (role-prompt splice OK).
  \item All $3K$ steps: recurrent feedback amplifies attention-kernel noise.
\end{itemize}

\vspace{0.3em}
\textbf{14B AIME control} (min cosine over 30 steps, item 0): HF sdpa vs eager $0.81$; HF vs fork $0.82$.
Fork drift is inside the HF kernel-drift envelope --- not a separate realign/RoPE bug.

\end{frame}

\begin{frame}{What we measure next}

\begin{itemize}
  \item Primary: unified fork vs HF-only LatentMAS (paper setup).
  \item Also: repaired hybrid, single-model vLLM, text-MAS vLLM.
  \item AIME 2024{+}2025, MATH-500 ($n{=}200$), GSM8K ($n{=}200$), Qwen3-14B.
  \item Concurrency 1/8/16/32/60 closed loop for vLLM arms.
  \item Throughput, p50/p95 latency, accuracy with paired bootstrap CIs, memory, preemptions.
  \item Greedy and sampled kept separate; single-model always reported.
\end{itemize}

\end{frame}

$n{=}50$, greedy, Qwen3-14B, $C{=}1$, $K{=}10$, max new 2048.

\begin{center}

\end{frame}

\begin{frame}{Takeaways}

\begin{itemize}
  \item One engine removes the hybrid handoff; GSM8K matches HF accuracy at $\sim 2\times$ lower p50.
  \item Single-model vLLM is reported (0.98 acc, 6.5 s p50, 68 tok/s) --- not hidden.
  \item AIME: speed win, accuracy loss under the same length budget; length caps dominate.
  \item Per-step latents match HF within normal SDPA/eager kernel drift on 14B.
\end{itemize}

\end{frame}
