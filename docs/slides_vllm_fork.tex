\begin{frame}{The gap}

\begin{itemize}
  \item Paper numbers use the \textbf{Hugging Face} LatentMAS path.
  \item Authors' ``vLLM support'' still runs latent agents on a second HF copy, then hands off via \texttt{prompt\_embeds} and a re-prefill.
  \item That handoff drops the in-engine KV and blocks the Judger on a CPU/GPU transfer.
\end{itemize}

\vspace{0.5em}
\textbf{Contribution:} a vLLM 0.11.1 fork where Planner / Critic / Refiner latent steps and Judger decode share one request and one KV.

\end{frame}

\begin{frame}{What the fork does}

\begin{itemize}
  \item Flag a request with a phase schedule: latent $\rightarrow$ role tokens $\rightarrow$ \ldots $\rightarrow$ decode.
  \item Latent step: next input is \texttt{realign(last\_hidden)} written into \texttt{inputs\_embeds}, not a sampled token embedding.
  \item Role prompts append as ordinary tokens on the \emph{same} request.
  \item Latent embeddings are stored so preemption / recompute replays them.
  \item Start with \texttt{enforce\_eager}, async scheduling off; stock or tail scheduler via \texttt{scheduler\_cls}.
\end{itemize}

\end{frame}
